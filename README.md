# Incident Management

Sistema de gestión de incidencias técnicas construido con Angular 20 como
parte del reto formativo de 30 días. Ver [`../PLAN.md`](../PLAN.md) para el
plan de trabajo completo.

## Requisitos previos

- Node.js `v22.22.1` (o compatible)
- npm `10.9.4` (o compatible)
- Angular CLI `20.3.32`

## Comandos principales

| Comando | Descripción |
|---|---|
| `npm install` | Instala las dependencias del proyecto. |
| `npm start` / `ng serve` | Levanta el servidor de desarrollo en `http://localhost:4200/` con recarga automática. |
| `ng generate component <name>` | Genera un nuevo componente standalone. |
| `npm run build` / `ng build` | Compila el proyecto de producción en `dist/`. |
| `npm test` / `ng test` | Ejecuta las pruebas unitarias con Karma. |
